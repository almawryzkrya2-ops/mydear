# مذكرات التشغيل والتخصيص

## التشغيل المحلي

1. تأكد من تثبيت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في VS Code.
3. شغّل:

```bash
npm start
```

4. افتح المتصفح على:

```text
http://localhost:3000
```

إذا كان المنفذ 3000 مشغولًا، استخدم:

```bash
PORT=3001 npm start
```

أو في PowerShell:

```powershell
$env:PORT=3001; npm start
```

## تخصيص المحتوى

كل النصوص الأساسية موجودة في ملف:

```text
public/content.js
```

يمكنك تعديل:
- اسم الحبيبة: `herName`
- اسم المرسل: `myName`
- عنوان المشروع: `title`
- نص اللغز: `puzzle.question`
- إجابة اللغز: `puzzle.answer`
- سنوات الآلة الزمنية: `years`
- الرسالة النهائية: `finalMessage`
- رسائل النجوم وترتيبها: `stars.messages`
- مقدمة النجوم وخاتمتها وزر المتابعة: `stars`
- نص الدعوة وصندوق الهدية والبطاقة: `gift`

الإعداد الحالي مخصص لريما من زكريا؛ تبدأ الحكاية بعام 2022، وتاريخ الخطوبة مضبوط على 09 / 04 / 2025. غيّر هذه القيم في `public/content.js` إذا أردت تحديثها.

### تعديل رسالة الهدية

حرّر `gift.paragraphs` و`gift.salutation` و`gift.closing` و`gift.signature` في `public/content.js`. لإضافة صورة اختيارية إلى البطاقة، ضع ملف الصورة داخل `public/images/` ثم عيّن `gift.image` إلى مسارها، مثل `/images/photo.jpg`. اترك القيمة فارغة لإخفاء الصورة. عند تعذر تحميل الصورة تبقى البطاقة والرحلة قابلتين للاستخدام.

تُحفظ البطاقة من زر «احتفظي بهذه الهدية» بصيغة PNG عالية الدقة باستخدام Canvas المدمج في المتصفح؛ لا تحتاج هذه الميزة إلى مكتبة أو خدمة خارجية. إذا أضفت صورة، يجب أن تكون من نفس الموقع حتى يمكن تضمينها في الملف المحفوظ.

تتذكر سماء النجوم ما اكتُشف خلال جلسة المتصفح الحالية. زر «العودة إلى البداية» يمسح هذا التقدم لتبدأ التجربة من جديد.

## النشر

هذا المشروع موقع ثابت؛ لا يحتاج عند نشره إلى Node.js أو قاعدة بيانات أو إعداد أمر بناء. الملفات الجاهزة للنشر كلها داخل `public/`.

### نشر مجاني سريع عبر Netlify

1. افتح [Netlify Drop](https://app.netlify.com/drop) من الكمبيوتر وأنشئ حسابًا مجانيًا أو سجّل الدخول.
2. في مستكشف الملفات، افتح مجلد المشروع ثم افتح المجلد `public`.
3. اسحب **مجلد `public` نفسه** إلى منطقة النشر في Netlify. لا ترفع مجلد المشروع الأب ولا مجلد `backup-original`.
4. انتظر اكتمال النشر؛ سيظهر رابط عام ينتهي عادةً بـ `netlify.app`. افتح الرابط وجرب الرحلة.
5. لتغيير اسم الرابط، افتح إعدادات الموقع في Netlify وابحث عن إعدادات اسم الموقع/النطاق، ثم اختر اسمًا متاحًا.
6. لتحديث النسخة لاحقًا، اسحب محتويات `public` المحدثة إلى قسم النشر اليدوي للموقع نفسه في لوحة Netlify، أو اربط مستودع GitHub لتحديثات تلقائية.

لنشره عبر GitHub وربطه باستضافة ثابتة، ارفع نسخة المشروع إلى مستودع تملكه ثم اتبع خطوات ربط مستودع Git من لوحة الاستضافة. إذا كان المستودع عامًا، فسيكون كود الموقع ونصوصه متاحًا للآخرين أيضًا.

**تنبيه خصوصية:** الرابط المنشور عام لمن يعرفه، وليس صفحة خاصة أو محمية بكلمة مرور. تجنب إضافة صور أو معلومات شخصية لا ترغب في أن يراها غير ريما، وتذكر أن ملفات الموقع الثابتة يمكن للزوار تنزيلها.

## ملاحظات المهمة
- المشروع خفيف وسريع ومناسب للهواتف.
- لا يعتمد على قاعدة بيانات أو خدمات خارجية.
- التسلسل: الباب السري، اللغز، محطات الذكريات، النجوم، الشمعة والرسالة، ثم صندوق الهدية والبطاقة.
- لا تظهر الرسالة الختامية إلا بعد إطفاء الشمعة، وتظهر الدعوة السرية إلى الهدية بعدها.
- تعمل الرحلة دون صور أو صوت؛ المؤثرات بصرية فقط، وتُخفف الحركة تلقائيًا عند تفعيل إعداد تقليل الحركة في الجهاز.
